# بوابة بوصلة التعريفية الجديدة — الاستكشاف والقصة المصورة والنموذج الحركي
**BOSLA Intro Redesign (`design/bosla-storyboard/`)**

يجمع هذا المجلد المعماري المعزول كامل مخرجات المرحلة الإبداعية لإعادة تصميم الصفحة الرئيسية التعريفية لـ **«بوصلة | BOSLA Academy»** باللغة العربية (`RTL`) دون تعديل أي من مسارات التطبيق الإنتاجي أو ملفات `package.json`.

---

## خريطة الملفات والواجهات القابلة للتشغيل

| المسار | الدور والوصف |
|---|---|
| [`CONCEPTS.md`](CONCEPTS.md) | مقارنة تفصيلية بين 3 مفاهيم متمايزة (المسرح المنقسم 50/50، بوابة المنظومة الحيوية، والصحيفة المطبوعية) ومبررات اختيار المفهوم الثاني |
| [`concepts.html`](concepts.html) | اللوحة البصرية التفاعلية لعرض اللقطات البطولية الثلاثة جنباً إلى جنب مع خطوط عربية حقيقية |
| [`STORYBOARD.md`](STORYBOARD.md) | القصة المصورة الكاملة (7 مشاهد بطول إجمالي `10.8vh`) مع حالات الدخول/الوسط/الخروج، تقريب عدسة المعايرة، التكيف للموبايل، وخطة التقنيات لكل مشهد |
| [`storyboard.html`](storyboard.html) | لوحة القصة المصورة المصممة للمراجعة البصرية على دقة الديسكتوب (`1440×900`) والموبايل (`390×844`) |
| [`prototype/index.html`](prototype/index.html) | **النموذج الحركي الحي (`Live Motion Prototype`)**: البطل متعدد الطبقات ← الانتقال التوقيعي بعدسة المعايرة (`GSAP ScrollTrigger` + `SVG Stroke` + `clip-path`) ← الأركان الأربعة ← الوقفة ← تدرج الطالب إلى المدير (`Three.js` الانتقائي الكسول) ← بوابة الدخول المستقرة |
| [`prototype/serve.mjs`](prototype/serve.mjs) | خادم HTTP محلي خفيف بلا اعتماديات إضافية يعمل على المنفذ `4321` |
| [`PERFORMANCE_PLAN.md`](PERFORMANCE_PLAN.md) | خطة الميزانيات التقنية والـ WebGL والـ FPS مع فصل صارم بين **القياسات الفعلية المرصودة** و**الأهداف المعمارية المستقبلية** |
| [`ASSETS.md`](ASSETS.md) | سجل جميع الأصول المحفوظة والأحجام الدقيقة وخارطة الدمج المستقبلي مع Next.js عند الاعتماد |

---

## تعليمات التشغيل المحلي السريع

من جذر المشروع (`bosla-academy`):

```powershell
node design/bosla-storyboard/prototype/serve.mjs
```

ثم افتح في المتصفح:
- النموذج الحركي الحي: `http://127.0.0.1:4321/prototype/index.html`
- مقارنة المفاهيم الثلاثة: `http://127.0.0.1:4321/concepts.html`
- القصة المصورة المصغّرة: `http://127.0.0.1:4321/storyboard.html`

> لتجميد حركة عدسة المعايرة عند نقطة تمرير محددة للفحص اليدوي: أضف `?p=0.35` أو `?p=0.62` إلى رابط النموذج.
